## 移动端阅读验证

这是一段独立编写的合成内容，用于检查中文换行、**强调文字**、`inline_code` 和文本选择。打开输入法后，输入区和主要操作应仍可到达。

```rust
fn main() {
    let message = "中文输入与 emoji 🦀";
    println!("{message}");
}
```

| 项目 | 需要观察的结果 |
| --- | --- |
| 文字 | 中文、英文、emoji 正常显示 |
| 输入 | 候选选择、删除和粘贴保持正确 |
| 滚动 | 内容可以连续滚动与选择 |
| 生命周期 | 切回前台后画面恢复 |

### 长文本

这段文字用于验证窄屏上的连续排版。正文应根据可用宽度换行，代码块允许独立滚动，主要操作不能被宽内容挤出窗口。旋转屏幕或改变字体大小后，滚动范围也应重新计算。

### 边界

此验证工程没有设备配对、网络连接或会话持久化。重新启动后恢复初始合成内容，输入结果只保存在当前进程内。
