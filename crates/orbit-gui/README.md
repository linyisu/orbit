# orbit-gui

实验性 GPUI Kit 桌面客户端，通过 `orbit-client` 使用工作区服务。提供项目与标签、对话、工作面板，以及账号、模型、MCP 和快捷键设置。

## 启动

先按 [根 README](../../README.md#快速开始) 准备工具链与配置。Ubuntu 的额外依赖：

```sh
sudo apt install build-essential clang pkg-config libfontconfig-dev libwayland-dev \
  libxkbcommon-x11-dev libx11-xcb-dev libssl-dev libzstd-dev libasound2-dev libvulkan-dev
cargo run -p orbit-gui --locked -- --config config.toml
```

支持 `--workspace`、`--model`、`--resume`、`--ssh` 与 `--wsl`，其他参数见 `--help`。GUI 内嵌静态服务，暂未加入便携打包。

## 使用

- 思考、说明、工具和答复按发生顺序展示；思考片段结束后自动收起，手动选择优先；工具直接逐条展示，不加外层折叠。
- 输入框上方仅在运行时显示当前状态及最新进度，不提供点击或悬停定位；说明在原位置渲染 Markdown。工具行显示名称、目的和前置状态图标，运行图标缓慢旋转，
  点击打开详情：命令分 stdout/stderr，文件变更显示已提交差异，只展示相关内容。
- 思考和工具处于同一层级；工具状态图标只在需要时插在名称前，不为成功项保留空位。思考正文带同色虚线。工具列表不限制高度，随会话统一滚动；展开或收起保留阅读位置并暂停跟随，滚轮或滚动条回到底部后恢复。工具行不显示悬浮标签。
- 会话区底部居中悬浮显示跟随入口：离开底部时，回复中为缓慢呼吸的省略号，结束后为下箭头；已在底部时隐藏，点击回到最新输出；右侧导航只保留轮次入口。状态行不重复显示正在生成的正文。
- 项目支持置顶和拖动排序；启动从共享客户端恢复标签、选中项和草稿，关闭当前标签后优先选择左邻。
- 侧栏顶部切换本地与远程环境；远程下拉列出 SSH 和 WSL，支持添加连接并记住最近选择；目录在新任务中选择。快捷入口为新任务、搜索、MCP、Skill 和插件。
- 远程连接的主机和目录使用可输入下拉；目录提供 `~/`、`../` 与子目录，支持键盘选择。
- 新会话在输入框上方选择目录及本地、SSH、WSL；切换目标保留草稿，右上角只保留工作面板入口。
- 输入区支持文件附件、图片、历史输入与暂存消息；粘贴文件自动生成附件卡片，达到 4096 字节或超过 32 行的文本转成文本附件。编辑暂存消息会撤回到输入框；响应时空草稿显示停止，有内容时显示发送。
- 输入框右侧的麦克风提供本地语音输入：首次点击在后台准备 Qwen3-ASR 0.6B 增量识别模型，首次约 1.88 GB，准备完成后再点击开始录音。录音时底栏隐藏附件、模式和模型选择，左侧取消、中间长波形、右侧完成录音与发送；波形使用实际 PCM 音量，持续静音或音频中断 320 ms 后回到平线；Qwen 每两秒在输入位置更新文字并修订暂定尾部，停顿后补齐标点，停止后补齐尾部文字并等待校正，可编辑后发送。取消或切换会话及页面会回滚语音预览；发送会提交当前可见文字并停止录音。手工编辑草稿会保留用户编辑并停止后续语音覆盖，错误会保留已有预览文字；录音没有固定时长上限，按实际采样数缓冲短暂积压并释放已处理音频。模型保存在客户端主机缓存，音频不上传，也不随 SSH/WSL 连接传输。下载、校验、加载和转写不阻塞界面，准备阶段显示进度并支持取消，重试从已下载的位置继续。
- 消息内图片在前、文件在后；发送前后的文件卡片均可点击查看只读文本并复制。输入框内附件与文字共用左边距。已发送附件通过所属会话服务读取，SSH/WSL 路径不由本机解释。
- 用户消息保留原文并支持悬停复制，AI 回答支持本地、网络、内嵌图片；整轮回复完成后才显示全文和代码块复制按钮。缺失历史图片不阻止继续会话。未指定语言的代码块显示 `text` 标签。
- 工作面板提供执行、计划、变更和 Agent；执行区内部滚轮不带动外层会话。审批和变更的统一差异只显示一列行号。
- 工具详情按内容呈现：命令脚本区按实际换行高度展开，最高占窗口高度的 20%，超出后内部滚动；读取和搜索仅在顶部显示路径或查询；已生效的编辑、写入以红绿差异为主体，不重复展示请求正文。任务、记忆、历史、验证证据与后台命令分别展示必要结果；失败调用按参数、权限、依赖、冲突和执行错误展示原因与处理提示，命令保留原日志；空调用不占面板。未知工具保留完整调用内容。结果页保持统一高度，复制图标固定在各内容区内部右上角，成功后显示两秒对勾。命令 stdout/stderr 在运行中按原始字节游标增量读取，位于底部时跟随新增输出；查看历史位置时保留滚动。命令长日志和网页快照由共享客户端读取完整内容，查看详情不重跑工具。
- 工具列表隐藏普通成功图标，直接展示模型调用的工具名称。ReadImage 在详情弹窗内显示图片路径和缩略图，点击后打开大图预览；ReadFile 使用文件原始行号。调用内容和其他结果页显示行号，长行自动换行，不预留代码折叠栏；等宽编辑器字号跟随全局文字大小设置，末行之后不预留滚动空白。
- 当前会话的工具审批和计划待审自动展示；关闭后保留手动入口，后台请求在切回时显示。操作弹窗沿用搜索任务的位置和间距；常规弹窗沿用搜索宽度，图片详情使用紧凑宽度。
- 技能与插件市场在全局设置中管理，无需连接会话；技能支持创建、编辑和完整包导入。
- “应用到当前会话”只改变所选会话；技能与插件可从会话移除，全局定义保持不变。应用快照可随会话恢复，市场更新不会自动覆盖。
- 插件目前应用包中的技能；详情保留 Hook、MCP、命令和 Agent 声明，这些组件不会自动运行。
- MCP 保存后可“应用到当前会话”，新工具从下一次发送开始使用。

常用快捷键：Ctrl+O 打开项目，Ctrl+W 关闭标签，Ctrl+. 停止响应；设置中可改绑。其他入口见 [功能对照](../../FRONTEND_PARITY.md)。

## 源码与外观

[workspace/](src/workspace/) 管理会话视图与设置，[conversation/](src/conversation/) 渲染消息，[backend.rs](src/backend.rs) 将窗口事件接入共享客户端。认证、配置校验、会话轮询与附件传输由对应共享 crate 提供，前端只保留交互和视图状态。

[speech.rs](src/speech.rs) 适配 GPUI Kit 的录音、波形和草稿插入；模型下载、校验和本地识别
由 `orbit-client::speech` 处理。隔离音源与真实模型验收见 [语音验收](tests/support/speech.md)。

GPUI Kit 使用固定的 fork 提交，补丁来源见 [依赖补丁](../../patches/README.md)。

Shell 入口为 [appearance/main.js](appearance/main.js)，主题位于 [appearance/theme.json](appearance/theme.json)。`--appearance DIR` 覆盖外观目录，调试构建监听脚本变化；外观脚本仅暴露主题接口。

## 验证

```sh
cargo test -p orbit-gui --features test-support --locked
```

[传输测试](tests/transport.rs) 使用隔离的 [fixture 服务](tests/support/server.rs)，不连接真实模型。原生验收使用 Xvfb、临时 HOME、配置、数据库和工作区，避免操作用户桌面。

补充指令贴着输入框展示，默认在本次回复完成后逐条启动新一轮；点击“引导”才进入当前任务的安全输入边界。撤回、编辑和断线恢复仍以服务端持久队列为准。
