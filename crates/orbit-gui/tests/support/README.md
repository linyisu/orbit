# GUI 合成夹具

这里的文本、命令、配置、路径和图像均独立编造或由程序生成。
不使用用户消息、截图、附件或日志作为测试、示例及手工验收数据。

按语法和交互结构保留覆盖：混合文字、代码、公式、表格、图片、审批、分页与状态切换。

会话分段验收发送 `chronological-disclosures`，依次生成三个思考、Markdown 说明和工具批次；
首批含 48 次调用。检查顺序与独立折叠、标题对齐及思考虚线；展开和收起应保持标题位置。
在长工具列表上滚动应移动整个会话，悬停不显示标签，点击仍打开详情。
手动展开后继续接收事件不抢回底部；显式回到底部后恢复跟随。

设置页原生验收沿用 [隔离启动方式](inspector.md)：分别检查浅色与深色、16 与 20 号字体、1180×800 与 800×560 窗口。
逐页验证短内容不滚动、长内容可滚到末尾、拖动滚动条后仍可切页并恢复位置。API 协议下拉需跟随控件宽度，支持方向键、Enter 与 Escape。
插件目录、已启用插件和市场来源分别检查最后一项可见；市场来源沿用弹窗正文滚动，避免叠加第二层滚动条。
组件用法参考 [Select](https://gpui-kit.com/component/select) 与 [Scrollable](https://gpui-kit.com/component/scrollable) 官方文档。

模型恢复验收使用 `--resume model-recovery --model fixture::local`。发送 `generated-model-failure`，确认错误通知出现；切换到 `fixture::other` 后，上下文应从 200% 更新为 5%，当前错误入口与通知消失，历史失败记录仍保留。

侧栏验收恢复独立生成的本地、SSH、WSL 标签；远程传输使用临时 PATH 中仅允许启动 fixture 的替身。检查启动即列出全部环境、分段切换记住上次选择、切换保留未发送草稿、五个快捷入口打开正确页面，以及下拉的方向键与 Escape。覆盖浅色、深色和 20 号字体下的最小窗口。

远程连接表单使用临时 SSH 别名、WSL 发行版和合成目录。检查主机下拉与输入框同宽、输入可筛选、方向键与 Enter 只选择选项、Tab 和 Escape 收起下拉；目录选择只更新一个输入框，覆盖 `~/`、`../`、带空格的子目录、读取失败与 SSH 验证。切换主机后旧目录不可复用，异步结果不得覆盖新输入。

全局扩展验收使用临时 HOME、XDG 配置与数据目录、合成技能和市场。检查未连接会话时仍可创建和导入；切换工作区时全局编辑草稿保留；只对选定会话应用与移除；其他会话、项目目录不变；市场刷新或移除后已有会话仍恢复原快照。覆盖浅色、深色、大字号和最小窗口，并检查加载、失败与断开状态。
打开全局页面也检查新任务快捷入口和设置导航的真实点击；初始化不得重入正在更新的 Workspace。应用扩展到空白会话后，新建任务不能丢弃该会话，恢复后的应用按钮应保持原状态。
