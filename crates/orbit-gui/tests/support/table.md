## 合成目录操作示例

| 编号 | 操作名称 | 示例步骤说明 | 示例命令 |
| :---: | :--- | :--- | :--- |
| 1 | **创建样本清单** | 在临时示例目录生成若干虚构的几何图形标签，给每个标签设置分类、颜色和编号。 | `samplectl catalog create --name amber`；`samplectl labels generate --count 17` |
| 2 | **建立分类索引** | 按标签的颜色和形状建立合成索引，在索引记录中保存虚构的柜子名称和排序值。 | `samplectl index build --by color`；`samplectl index list --format compact` |
| 3 | **更新目录备注** | 给同一组合成标签依次添加简短备注、较长备注和一段包含中文标点的说明，保留修改时间。 | `samplectl note add --group mint --text "synthetic note"` |
| 4 | **导出示例摘要** | 从临时目录读取合成记录，按分类生成摘要，再将结果写入专门的演示输出目录。 | `samplectl export --group pearl --output ./demo-output/catalog.json` |

示例结束。以上名称、数量、说明与命令均为合成内容。
