# orbit-tools

`orbit-tools` 是 Orbit 的工具集与执行适配库，为 AI Agent 提供一组完备、安全且受限的操作工具。`run_command` 在容器内执行；内置文件工具在宿主进程中使用受保护文件描述符访问。文档转换在独立离线沙箱进程中执行；图片处理和网页请求在宿主侧执行，MCP 服务是独立宿主进程；网页回退 Firefox 使用独立 Bubblewrap 命名空间、Seccomp 和临时 profile，不挂载工作区或宿主 HOME。

## 架构与核心设计

```text
模型 ToolCall
  → Agent 发出 ToolStarted
  → ToolRegistry 路由至目标工具实例
  → 工具执行参数校验与工作区安全检查
  → （按策略触发用户内联审批或自动授权）
  → 在受限沙箱或受保护工作区内执行操作
  → 返回结构化 JSON / 多模态结果
  → Agent 发出 ToolFinished 并将结果注入上下文
```

- **抽象解耦**：`orbit-agent` 仅依赖基础 `Tool` 特征对象，无需了解底层文件系统描述符或容器命名空间的具体实现。
- **Fail-Closed 边界**：所有文件工具强制通过安全文件描述符定位，坚决拒绝符号链接越界、`..` 相对逃逸与受保护文件别名访问。
- **分层审批策略**：文件系统能力由运行时权限引擎校验；工具审批由 CLI/TUI 模式、Git 分类与已有授权共同决定。

## 工具目录与功能详解

### 1. 文件读取与浏览

#### `read_file`
- **功能**：以安全方式读取工作区或已授权外部目录内的 UTF-8 文本文件。
- **参数**：`path`（相对或已授权绝对路径）、`start_line`（从 1 起始）、`start_char`（所选行内从 0 起始的 Unicode 字符偏移）、`max_lines`（默认 200，范围 1–500）、`cursor`（原样传回 `next_cursor`）。
- **约束与安全**：分块读取，单次扫描预算默认 64 MiB（`command.read_file_scan_bytes` 可调整，`0` 表示不限扫描量）、返回内容上限 32 KiB，不再按文件总大小拒绝；可读取指定的中间行。优先用返回的 `next_cursor` 续读，避免重新扫描开头；文件版本变化时游标失效。`total_lines` 在到达文件末尾前为 `null`。内部链接经描述符解析，越界、循环及保护目标被拒绝；超长行仍可使用 `next_start_line`、`next_start_char` 续读。TUI 的 `[start..=end]` 行号范围包含两端。

#### `list_files`
- **功能**：以广度优先遍历浏览目录树结构，无需启动外部 Shell。
- **参数**：`path`、`depth`（默认 1，范围 1–8）、`limit`（默认 200，上限 1000）、`offset`、`include_hidden`（默认 false）。
- **约束与安全**：单次响应上限 32 KiB；全次扫描上限 20,000 个条目（超出时返回 `scan_truncated=true`）；单目录枚举上限 10,000 项；受保护路径与敏感隐藏目录即使开启 `include_hidden` 也坚决不予列出。

#### `search_text`
- **功能**：在工作区内执行高效的字面量或正则表达式全文检索，无需启动 Shell。
- **参数**：`query`、`path`、`glob`、`context_lines`（前后上下文行数）、`limit`（最大匹配项，上限 500）、`offset`。
- **约束与安全**：自动遵循 `.gitignore` 与 `.ignore`；单文件跳过上限 2 MiB；全次搜索上限 20,000 个文件或 16 MiB 文本；返回带行号的匹配内容及 `next_offset` 分页游标。

#### `project_overview`
- **功能**：只读扫描项目目录、语言分布、构建清单、测试文件及相关源码候选，不运行仓库脚本。
- **参数**：`path`（默认 `.`）、`query`、`max_tokens`（默认 2500）。
- **约束**：遵循忽略规则；最多遍历 20,000 项、记录 4,000 文件、读取 96 文件及 2 MiB 内容，单个源文件读取上限 128 KiB。Rust、Python、JS/TS、Go 使用 tree-sitter 提取部分声明，其余情况使用词法回退；结果不是完整符号表或依赖图。

### 2. 精确编辑与写入

#### `edit_file`
- **功能**：对已有文件执行基于上下文锚点的精确局部替换，推荐日常代码修改使用。
- **参数**：`path`、`old_text`（精确待替换旧文本）、`new_text`（替换新文本）、`replace_all`（是否替换所有非重叠匹配）。
- **约束与安全**：建议先读取当前文件再提供上下文锚点；实现检查当前文本的精确匹配，未强制验证模型是否此前读过；默认强制唯一性检查，歧义多处匹配直接拒绝；需要人工审批时，TUI 显示差异预览；通过同父目录的临时文件写入、刷盘并原子重命名（atomic rename），避免直接覆盖时暴露半写入内容。

#### `write_file`
- **功能**：用于创建新文件或有意整体重写完整文件。
- **参数**：`path`、`content`。
- **约束与安全**：单文件大小上限 1 MiB；创建新文件时使用 `O_EXCL` / `NOREPLACE`，防止覆盖并发新增的文件；需要人工审批时展示交互式差异预览；新文件权限严格限制为 `0600`。

### 3. Git 与项目版本感知

#### 原生 Git 与内部 `git_inspect`
- **Agent 入口**：通过 `run_command` 执行原生 Git。命令分类参与审批；普通本地写入和远端写入可获得绑定具体请求、仓库与配置版本的 TUI 会话授权，危险或未分类命令进入相应审批路径。
- **内部工具**：`git_inspect` 实现仍保留用于内部核验、补丁与测试，但不再注册为 Agent 常规工具。提供结构化只读状态、差异与历史。
- **参数**：`view`（`status` / `diff` / `history`）、`limit`、`offset`、`staged`（查看暂存区）。
- **约束与安全**：工作区必须为 Git 根目录；显式剥离所有 pager、hooks、fsmonitor、外部 diff 及系统环境变量；`diff` 受 256 KiB 原始输出上限约束并支持分页；不修改任何索引或工作树。

- **当前实现限制**：Git 命令分类不是完整 Shell 解析器，不能作为任意脚本效果的安全证明；TUI 的 Git 授权保存在进程内，不跨进程持久化；仅复用相同命令、工作目录、访问权限、外部能力及仓库配置版本。危险命令和配置修改不复用普通 Git 授权。配置修改经批准并请求 `read_write` 后可写入，外部 Git 元数据需要相应外部授权和保护检查。

#### `git_push`
- **功能**：将一个本地分支普通推送到明确的 HTTPS 远端分支，使用用户全局 Git credential helper；需要远端写入审批，不能超过联网策略上限。
- **参数**：`remote_url`、`source_branch`、`target_branch`。不支持强推、删除、mirror 或 SSH；执行采用 `command.process_limits` 与默认命令超时。
- **认证边界**：宿主仅在批准后调用用户配置的 credential helper（30 秒、64 KiB 回执上限）；凭据经私有临时文件只交给可信沙箱 worker。worker 使用临时裸仓库引用只读源对象，不继承项目配置或 hooks，禁用 HTTP 重定向，不把凭据或远端原始响应写入工具结果。通用 `run_command` 不获得凭据。需要已配置可非交互读取凭据的全局 helper。

#### `git_export_patch`
- **功能**：将当前工作树的所有修改与新增文件导出为标准统一补丁，供用户在宿主环境中审查并应用。

### 4. 多模态与文档解析

#### `read_image`
- **功能**：读取工作区内的图片文件（PNG、JPEG、GIF、WebP），校验后复制至全局附件存储，并在下一次请求中作为原生视觉内容注入模型。
- **约束与安全**：单图大小上限 20 MiB；最长边超过 2048 像素时自动等比例缩放；Agent 对非视觉模型的 `read_image` 调用直接返回错误；请求中已有图片附件的文本降级属于模型请求投影的另一条路径。

#### `read_document`
- **功能**：基于 AnyDoc 在本地将各种文档格式（PDF、Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV）转换为 Markdown 文本。
- **约束与安全**：CLI 在独立离线 Bubblewrap 进程中转换，可取消并设 60 秒超时、512 MiB 地址空间与 64 MiB 输出限制；单个源文档上限 32 MiB。每次读取仍重新授权、读取并校验源内容哈希；相同内容、扩展名和 worker 文件版本复用进程内缓存（最多 4 项、64 MiB），工具实例释放后清空；转换时建立每 4096 字符一个定位点的索引，翻页不再扫描整个转换结果。按 Unicode 字符分页（默认 20,000，上限 60,000 字符）。库嵌入方应通过 `with_worker` 指定支持私有转换入口的可执行文件（如配套 `orbit-document-worker`）。

### 5. 命令执行与输出管理

#### `run_command`
- **功能**：在由 `orbit-runtime` 托管的 Linux Bubblewrap 沙箱容器中安全执行 Shell 脚本与命令。
- **参数**：`command`（脚本正文）、`cwd`（工作目录）、`timeout_seconds`（超时时限）、`background`（默认 false，后台执行）、`workspace_access`（`read` 或 `read_write`，默认 `read`）、`network`（`deny` 或 `allow`，默认 `deny`）。
- **约束与安全**：
  - 默认工作区挂载为只读；显式申请 `read_write` 并在通过审批后方可在工作区直接持久化修改。
  - `.env`、数据库和凭据等注册的受保护文件被遮蔽。原生 Git 元数据可见，读写随工作区模式变化；已有 Git 配置和 hooks 默认只读；经批准的 Git 配置操作在 `read_write` 下可写。
  - 进程资源配额：单文件和地址空间默认不限（`0`），`/tmp` 总配额默认 2 GiB（`max_tmp_bytes`）；文件描述符和进程/线程限制默认均为 1024，可通过 `command.process_limits` 配置。超时默认 120 秒，上限默认 600 秒。
  - 单次请求默认离线；`network="allow"` 显式申请联网，不能超过全局 `command.network` 上限（默认允许申请）。
  - stdout / stderr 持续排空并在工具结果中各保留末尾 32 KiB，附带总字节数与截断标记。

#### 后台命令
- `run_command(background=true)` 在审批及执行准备完成后返回 `job_id` 和可用的 `output_id`。同会话最多同时运行 8 个后台命令，沿用普通命令的权限、沙箱、执行超时和核验流程；普通工具调用仍按模型给出的顺序执行，后台命令的进程可以重叠运行。
- `wait_commands(job_ids?, mode="any"|"all")` 通过完成事件等待任意一个或全部任务，不轮询、不调用模型。省略 ID 时等待当前运行尚未交付的任务。
- `get_command_status(job_ids?)` 查询状态；省略 ID 时列出当前运行的任务，指定 ID 时附带有限输出预览。`cancel_commands(job_ids)` 请求取消指定任务，`cancelling` 表示进程仍在清理，最终为 `cancelled`。
- 未经显式等待获取的结果在下一次模型请求前合并投递，stdout/stderr 各最多 2 KiB 预览，完整保留日志通过 `read_command_output` 回读。显式等待已返回的结果不重复通知模型。
- AI 没有继续调用工具但仍有任务未完成时，Agent 自动暂停等待完成事件，再继续规划。切换或关闭仍在运行的标签不停止任务；取消当前运行或发生执行错误会取消其后台任务。任务 ID 仅对所属会话有效，进程不跨 Orbit 重启恢复，历史记录不触发自动重跑。

#### `read_command_output`
- **功能**：命令输出按会话流式存储在用户数据目录中（单流上限 16 MiB，会话滚动上限 128 MiB），模型可通过此工具按偏移分页回读保留的历史输出日志，超过配额的输出可能截断或被回收，避免超大输出塞满上下文。
- **并行日志**：运行中的日志不会被其他命令回收；所有并行流共享会话字节预算，预算不足时继续排空进程输出并标记保留日志截断。

### 6. 权限扩展与产物交付

#### `request_capability`
- **功能**：当命令或工具需要访问工作区外部的目录时，向用户显式发起能力授权申请。
- **参数**：`path`（目标绝对路径）、`access`（`read` 或 `read_write`）、`reason`（申请原因）。
- **约束与安全**：路径必须存在；工作区内普通路径返回已经授权。系统保留路径、受保护路径及与保护路径冲突的目录被拒绝。已有外部授权直接复用；需要新增授权时通过工具审批，记录到当前进程的会话授权集合并用于后续命令挂载。该集合不是跨进程持久化授权。

#### `export_artifact`
- **功能**：将当前会话 `/scratch` 或工作区中的普通文件复制到 Orbit 私有产物目录。支持 `/scratch/...`、`/workspace/...` 与相对路径；无前缀相对路径优先匹配 scratch，再尝试工作区。
- **约束与安全**：分块复制并计算 SHA-256，不整文件驻留内存。默认单文件 1 GiB，每会话 128 个文件及 4 GiB，可通过 `[command.artifacts]` 配置，`0` 表示不限；文件锁串行化配额检查和发布，失败清理临时文件，源文件复制期间变化会报错。返回真实宿主路径与校验和。

### 7. 网络检索与网页读取

#### `web_fetch`
- **功能**：直接获取公网已知 URL 的网页正文并转为结构化 Markdown。
- **约束与安全**：
  - 仅开放公网 80/443 端口，严格防范 SSRF，严禁访问内网及保留地址。
  - 支持 HTTP(S) 可信代理配置（`[web].proxy`）；当遇到 Cloudflare 浏览器挑战且配置了代理时，可使用独立 Bubblewrap 沙箱中的无头 Firefox 提取正文，仅挂载系统文件与临时 profile，进程退出/取消时 PID 命名空间一并清理。
  - 单次响应体上限 2 MiB，总超时 60 秒，最多 5 次重定向；按 Unicode 字符分页。

#### `web_search`
- **功能**：多引擎公共网络搜索，按配置顺序轮询 Google、Bing、DuckDuckGo。
- **参数**：`query`（1–512 字符）、`max_results`（1–10）、`language`、`region`、`freshness`。
- **约束与安全**：无需搜索引擎 API Key；自动规范化查询文本，对跟踪参数去除后去重；针对 429 限流进行实例级冷却退避。

## 外部 MCP 服务

CLI/TUI 的工具注册还可加载用户配置的 MCP 工具。启动配置的服务需传入 `--allow-mcp-start`；服务进程直接运行在宿主，清理继承环境但保留用户显式配置的环境变量。单次工具调用经过审批，审批不能限制服务进程自身的文件或网络能力。

## 审批模式与权限交互

TUI 使用 `/mode` 切换 `ask` / `auto` / `yolo`；非交互 `orbit chat --mode` 接受 `read-only` / `auto` / `yolo`，不能假设其具有 TUI 弹窗：

| 模式 | 行为特征 |
|---|---|
| `ask` | 默认人工确认修改、命令、MCP 和新增外部授权请求；已有文件或 Git 会话授权可能先行放行。只读文件工具不逐次弹窗。 |
| `auto` | 工作区内文件写入/删除自动批准；普通命令需同时满足离线、只读、无外部能力才能自动批准。Git 查询也遵守这些条件；危险或配置操作需审批。已有相同请求的会话授权可复用。 |
| `yolo` | 工具审批请求自动批准；文件保护及命令容器约束仍生效。此模式不会给宿主 MCP 程序增加容器隔离。 |

## 显式模板授权

`[permissions].read_templates` 和 `write_templates` 接受工作区内已有 `.env.*` 普通文件的精确路径。只有用户确认其是模板后才应配置；不会自动信任 `.env.example` 后缀。写授权同时允许读取，只有读授权时命令挂载只读，硬链接别名也不能提供写入通道。注册的认证、数据库等保护路径不能被模板授权覆盖。
