# orbit-tools

`orbit-tools` 是 Orbit 的工具集与执行适配库，为 AI Agent 提供一组完备、安全且受限的操作工具。所有工具均运行在由 `orbit-runtime` 建立的严格安全边界与沙箱环境内，并支持用户配置的交互式审批机制。

## 架构与核心设计

```text
模型 ToolCall
  → Agent 发出 ToolStarted
  → ToolRegistry 路由至目标工具实例
  → 工具执行参数校验与工作区安全检查
  → （按策略触发用户内联审批或自动授权）
  → 在受限沙箱或受保护工作区内执行操作
  → 返回结构化 JSON / 多模态结果
  → Agent 发出 ToolFinished 并将结果注入上下文
```

- **抽象解耦**：`orbit-agent` 仅依赖基础 `Tool` 特征对象，无需了解底层文件系统描述符或容器命名空间的具体实现。
- **Fail-Closed 边界**：所有文件工具强制通过安全文件描述符定位，坚决拒绝符号链接越界、`..` 相对逃逸与受保护文件别名访问。
- **分层审批策略**：统一接入运行时权限引擎，根据会话模式（`ask` / `auto` / `yolo`）决定交互确认逻辑。

## 工具目录与功能详解

### 1. 文件读取与浏览

#### `read_file`
- **功能**：以安全方式读取工作区或已授权外部目录内的 UTF-8 文本文件。
- **参数**：`path`（相对或已授权绝对路径）、`start_line`（从 1 起始）、`max_lines`（默认 200，范围 1–500）。
- **约束与安全**：文件大小上限 1 MiB；单次返回内容上限 32 KiB；强制通过 `openat` 配合 `O_NOFOLLOW` 打开，禁止跟随符号链接；自动截断超长行并标记 `truncated`。

#### `list_files`
- **功能**：以广度优先遍历浏览目录树结构，无需启动外部 Shell。
- **参数**：`path`、`depth`（默认 1，范围 1–8）、`limit`（默认 200，上限 1000）、`offset`、`include_hidden`（默认 false）。
- **约束与安全**：单次响应上限 32 KiB；全次扫描上限 20,000 个条目（超出时返回 `scan_truncated=true`）；单目录枚举上限 10,000 项；受保护路径与敏感隐藏目录即使开启 `include_hidden` 也坚决不予列出。

#### `search_text`
- **功能**：在工作区内执行高效的字面量或正则表达式全文检索，无需启动 Shell。
- **参数**：`query`、`path`、`glob`、`context_lines`（前后上下文行数）、`limit`（最大匹配项，上限 500）、`offset`。
- **约束与安全**：自动遵循 `.gitignore` 与 `.ignore`；单文件跳过上限 2 MiB；全次搜索上限 20,000 个文件或 16 MiB 文本；返回带行号的匹配内容及 `next_offset` 分页游标。

### 2. 精确编辑与写入

#### `edit_file`
- **功能**：对已有文件执行基于上下文锚点的精确局部替换，推荐日常代码修改使用。
- **参数**：`path`、`old_text`（精确待替换旧文本）、`new_text`（替换新文本）、`replace_all`（是否替换所有非重叠匹配）。
- **约束与安全**：必须严格基于已读内容提供上下文锚点；默认强制唯一性检查，歧义多处匹配直接拒绝；修改提交前触发 TUI 内联差异对比预览；通过同父目录的临时文件写入、刷盘并原子重命名（atomic rename），杜绝半写入损坏。

#### `write_file`
- **功能**：用于创建新文件或有意整体重写完整文件。
- **参数**：`path`、`content`。
- **约束与安全**：单文件大小上限 1 MiB；创建新文件时使用 `O_EXCL` / `NOREPLACE`，防止覆盖并发新增的文件；写入提交前展示交互式差异预览；新文件权限严格限制为 `0600`。

### 3. Git 与项目版本感知

#### `git_inspect`
- **功能**：提供结构化、只读且分页的 Git 仓库状态感知，免去模型自行拼装和解析 git 命令字符串。
- **参数**：`view`（`status` / `diff` / `history`）、`limit`、`offset`、`staged`（查看暂存区）。
- **约束与安全**：工作区必须为 Git 根目录；显式剥离所有 pager、hooks、fsmonitor、外部 diff 及系统环境变量；`diff` 受 256 KiB 原始输出上限约束并支持分页；不修改任何索引或工作树。

#### `git_export_patch`
- **功能**：将当前工作树的所有修改与新增文件导出为标准统一补丁，供用户在宿主环境中审查并应用。

### 4. 多模态与文档解析

#### `read_image`
- **功能**：读取工作区内的图片文件（PNG、JPEG、GIF、WebP），校验后复制至全局附件存储，并在下一次请求中作为原生视觉内容注入模型。
- **约束与安全**：单图大小上限 20 MiB；最长边超过 2048 像素时自动等比例缩放；若模型不具备视觉能力，自动在请求副本中降级为文本占位。

#### `read_document`
- **功能**：基于 AnyDoc 在本地将各种文档格式（PDF、Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV）转换为 Markdown 文本。
- **约束与安全**：本地纯文本解析，不上传任何外部服务；单个源文档上限 32 MiB；按 Unicode 字符分页（默认 20,000，上限 60,000 字符）。

### 5. 命令执行与输出管理

#### `run_command`
- **功能**：在由 `orbit-runtime` 托管的 Linux Bubblewrap 沙箱容器中安全执行 Shell 脚本与命令。
- **参数**：`command`（脚本正文）、`cwd`（工作目录）、`timeout_seconds`（超时时限）、`workspace_access`（`read_only` 或 `read_write`）。
- **约束与安全**：
  - 默认工作区挂载为只读；显式申请 `read_write` 并在通过审批后方可在工作区直接持久化修改。
  - 受保护路径（`.git`、`.env`、数据库、凭据）在沙箱内被 `/dev/null` 强制遮蔽。
  - 进程资源配额：单文件 64 MiB、地址空间 4 GiB、文件描述符 1024、最大进程数 1024。
  - stdout / stderr 持续排空并在工具结果中各保留末尾 32 KiB，附带总字节数与截断标记。

#### `read_command_output`
- **功能**：完整命令输出按会话流式存储在用户数据目录中（单流上限 16 MiB，会话滚动上限 128 MiB），模型可通过此工具按偏移分页回读完整的历史输出日志，避免超大输出塞满上下文。

### 6. 权限扩展与产物交付

#### `request_capability`
- **功能**：当命令或工具需要访问工作区外部的目录时，向用户显式发起能力授权申请。
- **参数**：`path`（目标绝对路径）、`access`（`read` 或 `read_write`）、`reason`（申请原因）。
- **约束与安全**：禁止申请工作区内部路径或系统受保护路径；经用户确认批准后，授权登记至当前会话，并在后续命令执行中自动转为有效挂载。

#### `export_artifact`
- **功能**：将 `/scratch` 中生成的编译结果或临时文件安全交付到 Orbit 私有产物目录。
- **约束与安全**：单文件上限 64 MiB，每会话上限 128 个文件及 256 MiB；返回真实宿主路径与 SHA-256 校验和。

### 7. 网络检索与网页读取

#### `web_fetch`
- **功能**：直接获取公网已知 URL 的网页正文并转为结构化 Markdown。
- **约束与安全**：
  - 仅开放公网 80/443 端口，严格防范 SSRF，严禁访问内网及保留地址。
  - 支持 HTTP(S) 可信代理配置（`[web].proxy`）；当遇到 Cloudflare 浏览器挑战且配置了代理时，支持通过临时无头 Firefox 会话隔离提取正文。
  - 单次响应体上限 2 MiB，总超时 60 秒，最多 5 次重定向；按 Unicode 字符分页。

#### `web_search`
- **功能**：多引擎公共网络搜索，按配置顺序轮询 Google、Bing、DuckDuckGo。
- **参数**：`query`（1–512 字符）、`max_results`（1–10）、`language`、`region`、`freshness`。
- **约束与安全**：无需搜索引擎 API Key；自动规范化查询文本，对跟踪参数去除后去重；针对 429 限流进行实例级冷却退避。

## 审批模式与权限交互

用户可通过 `/mode` 命令或全局配置切换运行模式：

| 模式 | 行为特征 |
|---|---|
| `ask` | **严格逐次确认**：所有修改文件、外部能力申请、沙箱命令执行均需用户在 TUI 弹窗中显式批准。 |
| `auto` | **智能边界放行**：工作区内只读命令、无外部挂载且只读的文件操作自动执行；工作区写命令、外部路径挂载、文件修改预览需用户确认。 |
| `yolo` | **自动批准**：自动放行所有操作与文件修改，但**沙箱容器隔离、系统调用限制与受保护路径遮蔽依然强制生效**。 |
