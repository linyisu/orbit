# orbit-client

[项目总览](../../README.md)

工作区客户端负责本地、SSH、WSL 连接、服务部署、认证交互、请求与事件订阅。`prepare_connection` 准备目标，`connect::Opened` 打开会话，`pump` 驱动交互请求，`prompt` 提供单次任务事件流。

## 工作区服务

本地进程、系统 OpenSSH 和 `wsl.exe` 使用同一请求协议。SSH 沿用 `~/.ssh/config`、跳板机、密钥代理与主机校验配置；TUI 的私有 askpass 通道处理指纹确认、密码、私钥口令和交互认证。WSL 在选定发行版中启动 Linux 服务。当前客户端依赖 Linux/Unix 接口，WSL 适配器要求调用环境能执行 `wsl.exe`。

部署服务检测目标系统和架构，将客户端提供的同架构静态程序上传至 `~/.cache/orbit/servers/<SHA-256>/orbit`。传输完成后校验并原子安装，重复连接复用同版本文件。服务在握手前执行运行检查。`--server` 支持目标端预装程序，`--upload-server` 支持指定兼容程序；自动部署的架构需与客户端一致。

SSH/WSL 默认使用本地配置、模型目录和配置引用的凭据。新会话使用客户端记住的上次模型选择；恢复会话使用该会话保存的模型。配置通过认证连接传入，存放在服务私有临时目录；目录权限为 0700，文件权限为 0600，正常退出时清理。远端 OAuth 刷新保存在该临时凭据库，当前客户端尚未将刷新结果同步回本地；需要重新认证时，在本地 `/connect` 登录后重新连接。`--config` 和 `--auth-dir` 指本地路径，`--database` 指目标路径。模型、工具、MCP、Skill 和项目指令在目标环境执行或发现，目标需提供相应网络与运行依赖。

本地 Rust 工具链路径在目标不存在时，配置安装过程查找目标 rustup 默认工具链或系统工具链。本地、SSH 和 WSL 默认使用普通进程执行；`[command].sandbox = true` 启用隔离，需要目标提供 `bwrap`、`prlimit` 和可用的用户命名空间。

服务支持历史恢复、流式事件、审批、取消、模型切换、旁路提问、附件、文件读取、项目任务、记忆、插件和子代理详情。客户端断开后任务继续运行，通过同一目标和会话 ID 接回。服务空闲 15 分钟退出，`--stop` 停止空闲服务。运行时的会话写入锁由服务持有。

请求 ID 与内容指纹保存在数据库中，用于重复投递确认。客户端按游标分页接收持久事件。服务退出或确认中断时，客户端提示检查历史；恢复会话标记中断任务，并由用户决定后续操作。协议输出和服务诊断使用独立通道。


`windows` 保存客户端窗口布局与重连参数，使用文件锁识别已退出的窗口。恢复记录包含本地、SSH 和 WSL 目标，按目标与会话 ID 去重；会话正文由目标数据库保存。`platform` 提供本地浏览器和外部编辑器交互。
