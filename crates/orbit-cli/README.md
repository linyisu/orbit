# orbit-cli

`orbit-cli` 是 Orbit 的命令行接口与终端用户交互系统（TUI）。它集成了基于 Ratatui 的高性能无闪烁渲染引擎、平滑流式输出呈现、多终端会话实时同步、交互式连接管理向导以及丰富的工程命令集。

## 架构与核心模块

```text
orbit-cli/
├── src/
│   ├── main.rs            # 命令行入口、子命令分发与信号处理
│   ├── auth_cli.rs        # 认证子命令；chat/sessions/projects 分发与实现位于 main.rs
│   ├── config.rs          # 配置文件解析、校验与运行时参数构造
│   ├── connections.rs     # 服务连接的持久化与热重载
│   └── tui/               # 现代化终端用户界面
│       ├── mod.rs         # TUI 主事件循环与运行协调
│       ├── app.rs         # UI 状态与事件应用
│       ├── frames.rs      # 帧调度器 (~120 FPS 限制与流式分批刷新)
│       ├── transcript.rs  # 对话流排版、行高缓存与二分视口定位
│       ├── session_sync.rs# 多窗口会话增量同步与回放
│       ├── theme.rs       # 统一语义颜色主题与语法高亮混合
│       ├── icons.rs       # 统一 Nerd Font 界面图标
│       ├── connect/       # 交互式连接管理向导面板
│       └── ...
```

## 终端界面（TUI）渲染引擎

### 1. 流式更新与高帧率调度 (`frames.rs`)
- 滚轮、键盘和窗口尺寸变动事件直接请求下一帧渲染，不等待模型输出周期。
- 帧调度器合并同一帧周期内的多次重绘请求，将常规绘制平滑限制在约 120 FPS。
- 模型流式文本输出按 33ms 粒度合并刷新，大幅降低极端高速输出对终端渲染造成的卡顿与 CPU 消耗。
- 采用终端同步更新协议（Terminal Synchronized Updates）原子提交整帧画面，避免在支持该协议的终端中出现半帧撕裂或闪烁。

### 2. 对话排版与行高缓存 (`transcript.rs`)
- 按消息和逻辑行精细缓存排版文本、自动换行高度与累计高度。
- 视口滚动通过二分查找快速定位可见消息和行，仅将可见物理行提交给渲染引擎，支撑超万行长对话流畅滚动。
- 严格遵循 Unicode UAX #14 规范进行断行排版，中文逐字换行，英文优先保持单词完整，Emoji 与组合字符保持在同一字素簇内。
- 智能跟随策略（Sticky Bottom）：用户向上滚动浏览历史时保持视口稳定；滚回底部后自动恢复随新输出滚动跟随。
- 窗口尺寸缩放时，视口以当前消息、逻辑行和字符偏移为锚点自动重定位，确保缩放前后聚焦相同文本。

### 3. 可折叠块与交互体验
- **界面图标**：复选框、工具预览、状态标记、导航与输入提示统一使用 Nerd Fonts 的 Material Design 图标，在 `icons.rs` 中集中定义；终端字体需包含 Nerd Fonts 字形。文本标点、框线和加载动画保留各自的排版字符。
- **工具调用摘要**：默认在行内仅展示一行单行摘要；悬停高亮，点击或按 `Ctrl+O` 可原地展开入参与完整执行结果，再次点击即可折叠。
- **文档与代码预览**：Markdown 文件的读取、写入结果，以及网页和文档提取正文复用消息的 Markdown 渲染，支持标题、列表、表格和链接。源码预览、消息代码块和文件审批共用语言识别与语法颜色，保留跨行高亮状态；代码块使用带背景的语言标签与同色边线，颜色按语言标识稳定生成，别名共用配色。未标注语言时显示 `text`，未支持高亮的语言保留代码原文；源码仍显示行号，编辑与审批保留原文和增删标记。
- **思考链展示**：模型思考进行时实时展示展开内容；思考完成后自动收起为小巧的计时徽标（例如“思考 7.5s”），支持手动点击二次展开。
- **输入编辑**：鼠标拖选或 Shift+方向键建立编辑选区，输入、粘贴及删除作用于选区；`Ctrl+A` 全选，`Ctrl+C` 优先复制选区。`Home/End` 移到行首/尾，`Ctrl+Home/End` 移到整段首/尾，`Ctrl+←/→` 按词移动。多行输入的上下键停在文本边界；单行可用上下键切换历史，`Ctrl+↑/↓` 在任意位置切换历史，并保留草稿与光标。浏览历史时暂停自动命令提示，回到草稿后也保留输入焦点；重新编辑后恢复提示，或按 `Tab` 主动打开、再按 `Tab` 补全选中项。普通消息保留缩进及末尾换行；反斜杠后按 Enter 仅在光标位于输入末尾时续行，运行中同样有效。
- **输入光标**：输入框、搜索框与连接表单使用终端原生常亮方块，输入法跟随实际焦点；图片、按钮及审批获得焦点时隐藏光标。输入框默认有淡色短拖尾，单步移动约 40ms、较远移动约 100ms；光标和输入法位置立即更新，拖尾保留文字字形。选区、弹窗、标签切换和尺寸变化会清除拖尾，静止时不额外刷新。在配置的 `[tui]` 中设置 `cursor_trail = false` 可关闭；终端自身支持的像素级拖尾由终端配置控制。
- **应用内鼠标选区**：直接拖拽鼠标即可选中聊天历史中的文本，选中时视图自动冻结。选区按原有颜色反色显示，保留语法配色及粗体、斜体、下划线；透明背景和低对比度文字使用清晰的深浅色搭配，中文与 Emoji 的整个字素统一着色。按 `Ctrl+C` 通过 OSC 52 协议直接复制到系统剪贴板。有选区时单击聊天内容只取消选区，再次单击才展开或折叠工具与思考块；可直接拖动建立新选区，点击输入框仍立即定位光标，`Esc` 也可取消选区。
- **链接与导航**：消息、展开的工具输出和 Markdown 表格中的网页链接支持悬停提示与 `Ctrl+Click` 打开；代码块中的示例保持普通文本。右侧对话导航可用滚轮浏览，圆点使用柔和的循环色差，细刻度显示导航范围；底部显示可见轮次与当前轮次，点击“当前”重新定位当前圆点，点击圆点跳转对话，点击底部向下箭头回到最新输出。
- **新会话首页**：发送消息前，权限设置和状态查询等操作的结果显示在首页输入框上方，长输出可滚动查看；成功切换目录仅更新底部目录栏，发送消息后切换为对话布局。

## 多终端会话实时同步

Orbit 原生支持在多个终端窗口或终端会话中同时打开和协同处理同一项目：

- **标签并发运行**：回复、本地回退或历史显示期间可直接切换、新建或关闭标签，原会话继续在后台处理；多个会话可同时执行。通过 + 或 `/new` 新建的标签使用本次启动 Orbit 的目录，恢复会话则使用该会话保存的工作区。关闭标签仅收起页面，可通过 `/resume` 重新打开。任务、scratch、权限和审批按会话隔离。后台需要确认时，标签显示“待审批”，重新打开后处理；退出程序会取消尚未完成的任务并保存恢复记录。
- **会话 scratch**：每个会话有独立的持久工作目录，供命令保存临时脚本、中间结果与缓存。命令沙箱中挂载为 `/scratch`，`HOME` 为 `/scratch/home`；`/workspace` 对应项目目录，`/tmp` 则在每次命令结束后丢弃。scratch 位于数据库旁的 `<数据库名>.workspaces/<会话 ID>`，恢复会话时继续使用，删除会话时一并清理。
- **共享状态同步**：所有窗口通过中央 SQLite 数据库同步消息记录、思考流、工具回执、标题与运行状态。运行中文字增量约每 200ms 同步至后台各窗口。
- **单写入者排他锁**：每个会话同一时刻仅允许一个窗口向模型发起推理请求；其他窗口发起请求时会安全保留草稿并友好提示等待。
- **窗口生命周期管理 (`tui_windows`)**：基于操作系统文件锁跟踪各个活动 TUI 窗口。执行 `/restore` 命令可跨窗口恢复上一轮未关闭的标签集合；退出时自动合并去重。

## 交互式服务连接管理 (`/connect`)

在 TUI 中输入 `/connect`，无需手动编辑配置文件即可添加或管理大模型服务：

- **官方账号连接**：直接通过内置 OAuth 流程授权 Google Antigravity、Google Gemini CLI、ChatGPT 等账号。
- **自定义 API 连接**：
  - 支持 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages 协议。
  - 支持任意自定义 Base URL（兼容本地 Ollama、vLLM 或第三方中转网关）。
  - 点击“读取模型”自动向服务的 `/models` 接口查询可用模型列表，无需逐个手填。
  - 支持原地展开模型高级设置：上下文总额度、独立输入窗口、最大输出上限、多模态支持以及思考强度档位。
- **凭据安全隔离**：通过 `/connect` 录入的 API Key 由 `orbit-auth` 写入独立凭据库，连接配置使用 `credential` 引用。手写配置仍支持明文 `api_key`（示例配置也展示该字段），不要把含真实密钥的配置提交到版本库。

模型接口提供的能力用于更新模型目录；对于只返回模型 ID 的官方 DeepSeek 接口，Orbit 为 `deepseek-flash` 和 `deepseek-v4-pro` 补充已核对的 `none / low / high / max` 思考档位，默认 `high`。手动管理的模型列表同样获得这些默认能力，显式配置的思考档位优先；其他端点和未知模型需由服务端或连接高级设置提供能力。

TUI 每秒检测配置文件变化，并每 15 分钟异步刷新账号模型目录；`/model refresh` 可立即刷新并打开模型选择器。能力变化同步到所有标签，保留仍受支持的当前思考档位；正在进行的回复使用原客户端和额度，结束后应用更新。自动更新不会打开选择器。

## 常用命令与交互指令

### 交互式快捷指令 (Slash Commands)

- `/connect`：打开连接配置向导面板。
- `/model [供应商::模型名]`：交互式或直接切换当前会话所用的模型与思考强度。
- `/model refresh`：刷新模型目录并同步当前会话的模型能力。
- `/reasoning [档位]`：查看可用思考档位，或设置当前模型的思考强度。
- `/compact`：手动触发上下文分层压缩，将旧工具记录归档并生成增量摘要。
- `/resume [会话ID]`：打开当前项目的历史会话列表，支持按标题模糊搜索并秒级恢复。
- `/restore`：打开窗口恢复选择器，恢复上一轮未关闭的会话标签。上方的“全选 / 清空”支持悬停和点击，显示已选数量；当前行的长标题自动横向滚动。按空格切换当前行的选择，`Enter` 恢复选中的会话；`Esc` 或 `Ctrl+C` 关闭选择器并清空恢复命令，返回输入框。单个会话恢复失败时保留原标签、显示原因，并继续恢复其余选中的会话。
- `/cd <目录>`：在保留会话历史的前提下平滑切换当前会话的工作区根目录。
- `/editor [初始文本]`：暂停接管终端，调出系统的外部编辑器（`$VISUAL` 或 `$EDITOR`）编写长文本草稿。
- `/mode [ask|auto|yolo]`：切换当前会话的权限审批模式。
- `/status`：查看当前会话 ID、数据库路径、上下文占用以及验证指纹状态。
- `/changes`：核对自当前任务开始以来的基线变更与文件修改收据。

### 命令行常用子命令

```sh
# 启动交互式 TUI
orbit tui

# 恢复指定历史会话
orbit tui --resume <SESSION_ID>

# 单次命令行对话模式
orbit chat "分析并修复 src/main.rs 中的编译错误"

# 认证管理
orbit auth login google
orbit auth list

# 会话与项目管理
orbit sessions list
orbit sessions show <SESSION_ID>
orbit projects list
```

## 多模态与附件支持

- **图片拖放与剪贴板读取**：支持直接将 PNG、JPEG、GIF、WebP 图片文件拖入终端，或使用 `Ctrl+V`（部分终端 `Alt+V`）直接通过 `arboard` 读取系统剪贴板位图。
- **去重存储**：附件自动复制到全局 `orbit.attachments` 存储池并按内容 SHA-256 去重，不向用户工作区目录写入垃圾缓存。
- **文档提取**：配合 `read_document` 工具，可直接让模型读取 PDF、Word、Excel、PPT 等文档的结构化 Markdown 解析结果。
