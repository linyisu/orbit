# orbit-cli

[项目总览](../../README.md)

`orbit-cli` 是 Orbit 的命令行接口与终端用户交互系统（TUI）。它集成了基于 Ratatui 的高性能无闪烁渲染引擎、平滑流式输出呈现、多终端会话实时同步、交互式连接管理向导以及丰富的工程命令集。

## 统一工作区连接（实验性）

在普通 TUI 内直接输入连接命令，远端会话作为新标签加入，与本地标签并列。可以同时连接多个 SSH 主机、WSL 发行版或同一环境中的多个工作区；切换标签保留草稿、模型、权限模式和运行状态，各自接收事件与审批。

```text
/ssh
/wsl
/ssh dev-host /home/me/project
/wsl Ubuntu /home/me/project --wsl-user me
/ssh another-host '/home/me/project with spaces' --config custom.toml
/local
```

`/ssh`、`/wsl` 或仅填写主机名的命令会打开配置弹窗：根据命令直接填写 SSH 主机或 WSL 发行版、用户名、端口、私钥路径；目录留空时，连接后可浏览远端目录并选择工作区。SSH 配置选择框读取 `~/.ssh/config` 及 `Include` 文件，选择别名会填入主机、用户名、端口和私钥路径，并保留别名对应的跳板机等 SSH 设置；也可选择“手动填写新服务器”自行填写。WSL 输入列出已安装的发行版。命令中明确指定目录则直接连接。表单与按钮可用 `Tab` / `Shift+Tab` 切换，`Enter` 激活当前项，`Esc` 返回或取消；目录列表默认选中“打开当前目录”，直接 `Enter` 即可确认；选中子目录后 `Enter` 进入，进入后再次 `Enter` 确认当前目录，也可直接点击底部“打开此目录”；路径输入框支持输入后 `Enter` 前往；连接期间可以切换其他标签。

连接日志实时显示环境探测、服务部署进度、SSH 诊断和握手状态。失败后可重试或修改配置，不会无限停在“连接中”。

`/new` 或标签栏的 `+` 在当前环境新建会话；本地标签使用启动目录，远端标签沿用其目标工作区和配置。`/local` 新建本地标签。远端 `/sessions` 列出目标工作区的历史，`/resume ID` 在新标签恢复。`/close` 关闭标签并选中左邻标签，最左侧关闭后选择剩余第一个；一个连接断开不影响其他标签，`/reconnect` 可接回原会话。远端标签暂不加入本地 `/restore` 清单，重启后使用 `/ssh … --resume ID` 或 `/wsl … --resume ID` 恢复。

`orbit connect` 仍可从命令行进入同一套工作区标签界面，或执行无交互操作。本地进程、系统 SSH 和 `wsl.exe` 使用相同服务协议；`connect` 的本地入口也经过服务，普通 TUI 本地标签保留现有执行方式。

```sh
orbit connect --workspace /path/to/project
orbit connect --ssh dev-host --workspace /home/me/project
orbit connect --wsl Ubuntu --wsl-user me --workspace /home/me/project
orbit connect --ssh dev-host --workspace /home/me/project --list
orbit connect --ssh dev-host --workspace /home/me/project --resume SESSION_ID
orbit connect --workspace /path/to/project --prompt '检查测试失败原因'
orbit connect --workspace /path/to/project --stop
```

SSH 使用系统客户端，因此沿用主机别名、跳板机、密钥代理及主机校验配置；不关闭主机校验。TUI 内通过私有 askpass 通道显示首次主机指纹确认、密码、私钥口令及交互认证提示，敏感输入遮蔽显示，不保存到聊天记录、配置文件或命令参数。认证等待不计入连接超时。相同连接的新标签复用私有 SSH 主连接，各标签的认证提示独立；最后一个标签关闭后清理主连接。可用 `--ssh-user`、`--ssh-port`、`--identity` 覆盖 SSH 配置。WSL 直接启动选定发行版的 Linux 进程，无需安装 SSH 服务。本仓库的客户端仍依赖 Unix/Linux 接口；WSL 启动适配器需要当前环境能执行 `wsl.exe`，Windows 原生客户端尚未完成。

首次 SSH/WSL 连接检测 Linux 系统与架构，优先上传客户端旁的 `orbit-server-<架构>-linux-musl` 静态服务程序（x86_64 / aarch64），不依赖远端 glibc 版本。服务安装到目标用户的 `~/.cache/orbit/servers/<SHA-256>/orbit`，校验后原子替换；已有相同版本会复用。上传、复用或指定预装程序时都会先验证目标能否运行，再开始握手。缺少静态服务程序时兼容旧行为，尝试上传本机程序；不兼容时在部署阶段明确报错，不再只显示握手 EOF。

发布包须将客户端和静态服务程序放在同一目录。从源码构建时，先安装 `musl-tools` 和相应 Rust musl target，再运行 `scripts/build-bundle.sh`（开发构建用 `scripts/build-bundle.sh debug`）；输出在 `target/bundle/`，同时为 `target/release/orbit` 或 `target/debug/orbit` 配齐服务程序。CI 生成 x86-64 Linux 压缩包，并在隔离的 Ubuntu 20.04 容器里验证自动部署、服务握手与缓存复用；AArch64 可在对应 Linux 主机上运行同一脚本构建。

异架构或自定义构建可用 `--upload-server /local/path/to/linux-orbit`；`--server /remote/path/to/orbit` 连接预装服务。目标仍需运行命令所需的 `bwrap`、`prlimit` 和用户命名空间。部署不要求目标访问下载站点，也不修改目标系统库。

`--config`、`--database`、`--auth-dir` 指目标环境中的路径。默认配置为工作区内的 `config.toml`，相对配置和数据库路径相对目标工作区；认证目录默认取目标用户的配置目录。服务使用目标环境的模型凭据、网络代理、Skill 和 MCP 配置，不隐式复制本机账号。`--allow-mcp-start` 仍需显式指定。

远端标签支持流式对话、工具卡片、审批、取消、模型及权限模式切换、Markdown、图片与公式。目标文件通过已有连接中的权限检查接口读取，公式在本机排版；网络图片目前由本机下载，尚未接入目标环境的 `[web]` 配置。`/help` 列出远端命令；`Ctrl+C` 取消当前标签的任务，`Ctrl+D` 或 `/quit` 退出界面。关闭远端标签或退出界面只断开连接，服务中的任务仍会继续；普通本地标签退出时沿用取消规则。运行中追加指令、输入图片附件及其余本地斜杠命令暂未接入远端，输入会保留并明确提示限制。`--prompt` 是无交互入口，使用 auto 策略，需额外审批的请求会明确拒绝。

远端连接代理与服务进程分开：断开连接不取消任务，待审批请求也会保留；再次连接相同目标并指定会话 ID 即可接回。服务无运行中任务且 15 分钟没有请求时退出；`--stop` 只停止空闲服务。任务执行期间服务持有会话写入锁，其他进程不能接管写入。机器或服务退出后，恢复历史会标记中断，不自动重跑旧任务。

请求 ID 和内容指纹保存在会话数据库中，重复投递不会重复启动任务；若服务在接收与确认之间退出，返回结果不确定的提示，要求先检查历史。连接中断不会自动重发写操作。客户端按事件游标分页读取，重接会话时从持久历史恢复。协议标准输出与日志分离，并跳过协议握手前的有限登录横幅；日志位于目标临时目录的私有 `orbit-workspace-<uid>` 目录。

实现按职责分在 [workspace/setup.rs](src/workspace/setup.rs)、[transport.rs](src/workspace/transport.rs)、[bootstrap.rs](src/workspace/bootstrap.rs)、[server.rs](src/workspace/server.rs)、[session.rs](src/workspace/session.rs)、[interaction.rs](src/workspace/interaction.rs)、[discovery.rs](src/workspace/discovery.rs)、[directories.rs](src/workspace/directories.rs) 和 [run.rs](src/workspace/run.rs)；服务前端在 [workspace_client.rs](src/tui/workspace_client.rs)。测试使用真实本地服务、模拟模型和 SSH/WSL 启动替身，覆盖断连审批、取消、服务重启后去重、路径引号、横幅和部署校验；Windows/WSL 环境仍需实机验证。

## 渲染与输入的实现入口

[render.rs](src/tui/render.rs) 保留帧和视口协调，工具卡片、思考内容、安全终端文本与链接悬停分别放在 [render/tool_cards.rs](src/tui/render/tool_cards.rs)、[render/thinking.rs](src/tui/render/thinking.rs)、[render/text.rs](src/tui/render/text.rs)、[render/links.rs](src/tui/render/links.rs)，通过原渲染入口调用。代码语法高亮仍统一使用 [code.rs](src/tui/code.rs)，没有为各工具复制渲染实现。

[attachments.rs](src/tui/attachments.rs) 处理图片路径、剪贴板和附件状态；[media.rs](src/tui/media.rs) 与 `media/` 负责异步解码、布局、协议和预览。图片文件读取复用模型层的有界读取策略。

[markdown/table.rs](src/tui/markdown/table.rs) 共用 Markdown 与 HTML 表格排版，在媒体尺寸确定后组合单元格，保留列对齐、边框、链接与复制元数据；单元格内的图片和公式调用同一媒体接口。

主循环、渲染和对话框的大段测试分别位于 `tui/tests.rs`、`tui/render/tests.rs` 和 `tui/dialogs/tests.rs`，模块私有行为继续由原测试模块检查。

## 终端界面（TUI）渲染引擎

### 1. 流式更新与高帧率调度 (`frames.rs`)
- 滚轮、键盘和窗口尺寸变动事件直接请求下一帧渲染，不等待模型输出周期。
- 帧调度器合并同一帧周期内的多次重绘请求，将常规绘制平滑限制在约 120 FPS。
- 模型流式文本输出按 33ms 粒度合并刷新，大幅降低极端高速输出对终端渲染造成的卡顿与 CPU 消耗。
- 采用终端同步更新协议（Terminal Synchronized Updates）原子提交整帧画面，避免在支持该协议的终端中出现半帧撕裂或闪烁。

### 2. 对话排版与行高缓存 (`transcript.rs`)
- 按消息和逻辑行精细缓存排版文本、自动换行高度与累计高度。
- 视口滚动通过二分查找快速定位可见消息和行，仅将可见物理行提交给渲染引擎，支撑超万行长对话流畅滚动。
- 严格遵循 Unicode UAX #14 规范进行断行排版，中文逐字换行，英文优先保持单词完整，Emoji 与组合字符保持在同一字素簇内。
- 智能跟随策略（Sticky Bottom）：用户向上滚动浏览历史时保持视口稳定；滚回底部后自动恢复随新输出滚动跟随。
- 窗口尺寸缩放时，视口以当前消息、逻辑行和字符偏移为锚点自动重定位，确保缩放前后聚焦相同文本。

运行中的工具名称沿用黄色，思考标识沿用原来的颜色，并在原位渐亮；正文、命令参数和布局保持稳定，结束后停止动画。底栏只补充等待模型响应、上下文压缩等不可见阶段，不重复显示思考和工具执行文案。等待审批时停止动画，取消或结束后及时更新。本地 TUI 与工作区连接入口共用同一状态显示。

### 3. 可折叠块与交互体验

#### 界面图标

复选框、工具预览、状态标记与导航统一使用 Nerd Fonts 的 Material Design 图标，在 `icons.rs` 中集中定义；终端字体需包含 Nerd Fonts 字形。输入与消息框提示符使用 Unicode `❯`。文本标点、框线和加载动画保留各自的排版字符。

#### 工具调用摘要

默认展示单行摘要；只有连续同名且操作对象相同的调用才合并，汇总行显示对象，调用次数放在末尾。文件按路径区分，子代理按代理区分，命令日志按日志和输出流区分，搜索还须匹配搜索词与范围；分页位置不影响分组。无法确定对象的扩展工具及创建新记录的调用不自动合并。展开分组后，汇总标题与各次调用一起放入同一个外框，宽度与普通工具卡片一致；汇总标题下留一行空白，组内收起的调用连续排列、不加空行或分隔线；展开某次调用时，以连接外框的分隔线界定该次调用的内容范围，整组收起时仍为单行摘要。

子代理读取显示任务名称和回答、工具调用或空结果等实际内容，不以内部 ID、消息编号及字符游标作为摘要。点击调用标题，在框内直接展开入参与完整结果，不再嵌套工具框；点击展开内容收起该次调用，图片两侧的留白在每一行都可收起，点击图片本身仍打开预览；点击汇总行整体收起。收起的工具块之间保留一行空白；展开框的上下边线代替相邻的空行。思考、消息、不同工具、失败调用和带“查看”入口的子代理任务分开显示；分组仅影响界面，历史与模型上下文保留原始调用。悬停高亮，展开后的多行标题按最终排版整段高亮，滚动与窗口缩放后保持一致，不改变结果正文与边框的样式；点击或按 `Ctrl+O` 展开、折叠。

#### 文档与代码预览

数字与命名脚注（`[^1]`、`[^note]`）按引用顺序统一显示为 `[1]`、`[2]`；单击定位到同一条消息中的对应脚注，并用主题高亮底色标记正文两秒，不弹出外部链接提示。脚注正文保留 Markdown 格式与多段内容，流式更新和窗口缩放后继续保持定位；旁路和子代理弹窗共用此交互。未定义、转义或代码中的脚注标记保持字面内容。暂不支持文档标题锚点跳转；Markdown 和 HTML 的 `#fragment` 链接只显示普通文字，不提供链接样式或点击入口。

HTML details 收起和展开使用同一套右、下尖括号，悬停时使用主题强调底色与深色文字，提高透明终端中的对比度。代码块边框在嵌套 details、缩进与换行后保留语言主题色，底部边角与顶部、竖线一致。

文件的读取、写入和编辑预览保留源码与行号，Markdown 文件也按 Markdown 语法着色，不转换为正文。网页和文档提取正文复用消息的 Markdown 渲染，支持标题、列表、表格和链接。源码预览、消息代码块、搜索结果、JSON 输出和文件审批共用 `code.rs` 渲染器，统一语法颜色、行号栏、Unicode 换行与裁切及增删底色，保留跨行语法状态；搜索仅额外提供命中范围。Markdown 源码完整保留语法符号，通过同一语法包着色并叠加标题加粗、粗体、斜体、嵌套强调、删除线和 `==高亮==` 的效果；行内代码与转义示例保留字面内容。

`$…$` / `$$…$$` 公式内容复用 LaTeX 语法。各语言注释统一使用清晰的浅灰色。消息正文、思考和提取的文档正文共用同一行内渲染器，HTML 使用 `html5ever` 的 tokenizer 与树构建器，再映射到共用的行内样式与块级布局，支持强调、下划线、高亮、代码、链接、图片替代文本、引用块、段落、提示框、分割线和 HTML 表格（含 `colspan` 与单元格对齐）。

`details/summary` 有独立的折叠状态，支持嵌套、`open` 属性、内部 Markdown 和点击展开；指示符与正文对齐，悬停底色连续覆盖标题及空格，保留标题本身的语义样式；主界面与只读会话弹窗复用交互。`sup/sub/small/abbr/q/kbd` 沿用不支持的 HTML 标签的统一回退，标签、属性及内部文字直接显示和复制，不替换字符或模拟效果。图片等待加载时保留替代文本，链接图片保留外层跳转目标。

CSS 通过 `cssparser` 解析，支持不透明十六进制/命名颜色、背景色、字重、斜体、文字装饰、对齐、左侧边线及映射到单元格的留白，忽略其他样式。HTML 段落、提示框和 Markdown/HTML 分割线共用正文两侧留白，外侧留白不继承块内背景。链接范围按最终显示文字计算，换行、对齐和流式更新后仍可点击。源码与代码块保留 HTML 标签；未知构造保留原文，不执行脚本或加载外部样式。代码块使用带背景的语言标签与同色边线，颜色按语言标识稳定生成，别名共用配色。

未标注语言时显示 `text`，未支持高亮的语言保留代码原文；源码仍显示行号，编辑与审批保留原文和增删标记。

#### 图片与公式预览

消息、思考、文档正文与展开的 `read_image` 共用异步媒体管线，本地 PNG、JPEG、WebP、GIF（首帧）及 SVG 直接在正文中显示图片；可见的网络图片异步下载并直接显示，等待或失败时保留替代文本。单击图片打开预览弹窗，滚轮、`+`/`-` 或“放大/缩小”按钮调整倍率（25%–800%，每步约 6%，100% 为适应窗口）；放大后可拖动或用方向键移动查看，`0` 或“适应”恢复完整视图，`Esc`、关闭按钮或点击弹窗外关闭。正文、思考、工具输出与会话弹窗共用预览；拖选正文图片仍用于选择和复制。

预览按窗口实际可用空间计算缩放，超过可用边界后才裁切，兼容大窗口与高像素密度。直接连接 Kitty 协议终端时，缓存预算内的位图原图只上传一次，缩放和拖动通过小型位置与裁切命令更新，复用同一图片放置；关闭预览清除放置。输入队列中的连续移动或拖动合并到最新坐标，保留按下、松开、按键及修饰键的顺序；松开时采用最终坐标。

tmux、其他图像协议、SVG、公式及超过原图缓存预算的图片沿用工作线程裁切、重绘与编码，仅生成窗口内的像素；SVG 保留透明背景并按倍率重绘。连续操作复用文件内容、已解码位图或 SVG 树，跳过过时的待执行视图，并显示已完成的中间画面；位图操作期间使用快速采样，停下后补上清晰版本。网络下载和本地图片/公式使用独立的有界队列，慢速图片站点不阻塞本地媒体。使用终端能力查询选择 Kitty、Sixel 或 iTerm2 图像协议；Kitty 正文图片、缩略图和公式使用未压缩的 RGBA 传输，预览原图使用 PNG，均不叠加协议层 zlib 压缩，避免部分终端在大图解压时崩溃，不需要额外配置。不支持像素图形时图片降级为半块字符，公式保留 TeX 文本。

Markdown 的 `$…$` / `$$…$$` 由同一 Markdown 解析器识别，RaTeX 解析与排版后生成嵌入字形的透明 SVG，再复用图片管线；行内公式按基线与文字对齐，块级公式独占区域并按正文可用宽度居中。Markdown 与 HTML 表格的单元格也复用媒体排版，公式按列宽缩放，保留单元格对齐、跨列、边框与链接；仅对可见表格行申请解码，不支持像素公式时保留 TeX。公式和图片可在正文、思考及会话弹窗中滚动、裁切，公式仍可点击打开预览。源码代码块不转换为图像。拖选触及任意图像行即选中整块公式或图片，选中底色和图像着色在媒体工作线程内预先生成，不依赖某种终端的选区叠加能力；取消选择恢复原图，重复出现的同一图片或公式各自独立。

公式中的中文沿用系统 Unicode 字体回退，字体发现诊断默认静默，不直接写入终端输入区域；字体缺失时保留 TeX 文本。RaTeX 字体模块的临时日志补丁及升级移除条件见 [补丁 README](../../vendor/ratex-unicode-font/README.md)。

复制公式返回一次完整 TeX，即使只选中被裁切的一部分；图片仍复制替代文本，生成的图片协议、边框与思考竖线不进入剪贴板。仅加载当前可见区域，缓存有数量和内存上限；SVG 不读取外部资源，网络图片复用网页工具的代理路由、地址与重定向检查，失败时保留文字。网页、搜索与图片自动沿用启动环境里的代理变量和 `NO_PROXY`；可选 `[web].proxy` 显式覆盖。恢复会话时图片使用重新加载的网络配置，缓存按网络策略隔离；终端能力、本地图片与公式缓存仍可共享。

#### 思考链展示

模型思考进行时实时展示展开内容；思考完成后自动收起为小巧的计时徽标（例如“思考 7.5s”），点击徽标展开。展开后点击整个思考区域即可收起，包括文字两侧留白与内部空行；块间分隔空行不参与点击。拖选仍用于复制，不触发收起。

#### 输入编辑

鼠标拖选或 Shift+方向键建立编辑选区，输入、粘贴及删除作用于选区；`Ctrl+A` 全选，`Ctrl+C` 优先复制选区。`Home/End` 移到行首/尾，`Ctrl+Home/End` 移到整段首/尾，`Ctrl+←/→` 按词移动。多行输入的上下键停在文本边界；单行可用上下键切换历史，`Ctrl+↑/↓` 在任意位置切换历史，并保留草稿与光标。浏览历史时暂停自动命令提示，回到草稿后也保留输入焦点；重新编辑后恢复提示，或按 `Tab` 主动打开、再按 `Tab` 补全选中项。

普通消息保留缩进及末尾换行；反斜杠后按 Enter 仅在光标位于输入末尾时续行，运行中同样有效。

用户消息显示时优先从词间空格处折行，换行处分隔用的连续空格不占据下一行，避免把后半句挤到最右侧。能放进一行的空格、显式换行和缩进照常保留；发送与保存的提示词仍为原文，源码和工具输出保持原有排版。

#### 输入光标

输入框、搜索框与连接表单使用终端原生常亮方块，输入法跟随实际焦点；图片、按钮及审批获得焦点时隐藏光标。输入框默认有淡色短拖尾，单步移动约 40ms、较远移动约 100ms；光标和输入法位置立即更新，拖尾保留文字字形。选区、弹窗、标签切换和尺寸变化会清除拖尾，静止时不额外刷新。在配置的 `[tui]` 中设置 `cursor_trail = false` 可关闭；终端自身支持的像素级拖尾由终端配置控制。

#### 应用内鼠标选区

直接拖拽鼠标即可选中聊天历史中的文本，选中时视图自动冻结。选区使用统一的柔和灰紫底色，保留文字、语法色相及粗体、斜体、下划线；低对比度文字适度提亮。消息外框、代码块边线与语言标签、表格网格及单元格填充保持原样，行首/尾留白与空白行不铺色；代码中的真实边框字符仍可选中。中文与 Emoji 的整个字素统一着色。按 `Ctrl+C` 通过 OSC 52 协议直接复制正文到系统剪贴板，去掉生成的框线、语言标签与思考竖线，保留正文缩进、空行与原文中的框线字符；表格去掉网格但保留列间距。

有选区时单击聊天内容只取消选区，再次单击才展开或折叠工具与思考块；可直接拖动建立新选区，点击输入框仍立即定位光标，`Esc` 也可取消选区。

#### 链接与导航

消息、源码代码块、展开的工具输出和 Markdown 表格中的网页链接支持悬停提示与 `Ctrl+Click` 打开，换行后的网址片段保留完整目标。Markdown 超链接只显示标题；Markdown 与 HTML 图片直接显示，来源为 HTTP(S) 地址的图片在悬停时提示 `Ctrl+Click` 跳转到图片地址，本地图片不自动生成网页跳转。`[![图片](来源)](目标)` 或 `<a href="目标"><img src="来源"></a>` 形式的链接图片优先使用外层链接目标，整个图片区域均可跳转；普通单击打开图片预览，关闭后恢复正文交互。引用式链接使用文档内的定义解析，直接显示的网址与引用定义中的网址也可打开。`web_fetch` 标题中的网址用于展开工具，展开后的内部网址可打开。

文字与图片链接共用同一套悬停提示样式，提示固定在当前链接主体下方，不随鼠标移动或切换到上方、侧边、页面远处。同一段换行文字或同一张图片使用一个悬停区域；提示可临时覆盖其他内容，移开鼠标后恢复原内容，不覆盖当前悬停主体。主体下方超出视口时不显示提示，`Ctrl+Click` 仍可使用。

右侧对话导航可用滚轮浏览，圆点使用柔和的循环色差，细刻度显示导航范围；底部显示可见轮次与当前轮次，点击“当前”重新定位当前圆点，点击圆点跳转对话，点击底部向下箭头回到最新输出。

#### 新会话首页

发送消息前，模型、思考档位、权限、目录、任务和记忆等修改直接更新状态，不追加操作提示。主动查询与操作失败使用临时弹层，支持滚轮和翻页，`Esc`、`Ctrl+C` 或 `Enter` 关闭；内容不写入对话区。发送消息后切换为对话布局。

## 多终端会话实时同步

Orbit 原生支持在多个终端窗口或终端会话中同时打开和协同处理同一项目：

- **标签并发运行**：回复、本地回退或历史显示期间可直接切换、新建或关闭标签，原会话继续在后台处理；多个会话可同时执行。本地通过 + 或 `/new` 新建的标签使用本次启动 Orbit 的目录，远端标签沿用其目标工作区，恢复会话则使用该会话保存的工作区。关闭标签后焦点切到它左侧相邻的标签；关闭最左侧标签时，切到剩余标签中的第一个；关闭最后一个标签则打开新的首页。关闭标签仅收起页面，可通过 `/resume` 重新打开。任务、scratch、权限和审批按会话隔离。后台需要确认时，标签显示“待审批”，重新打开后处理；退出程序会取消普通本地标签尚未完成的任务并保存恢复记录；远端服务任务继续运行。
- **会话 scratch**：每个会话有独立的持久工作目录，供命令保存临时脚本、中间结果与缓存。命令沙箱中挂载为 `/scratch`，`HOME` 为 `/scratch/home`；`/workspace` 对应项目目录，`/tmp` 则在每次命令结束后丢弃。scratch 位于数据库旁的 `<数据库名>.workspaces/<会话 ID>`，恢复会话时继续使用，删除会话时一并清理。
- **共享状态同步**：所有窗口通过中央 SQLite 数据库同步消息记录、思考流、工具回执、标题与运行状态。运行中文字增量约每 200ms 同步至后台各窗口。
- **单写入者排他锁**：每个会话同一时刻仅允许一个窗口向模型发起推理请求；其他窗口发起请求时会安全保留草稿并友好提示等待。
- **窗口生命周期管理 (`tui_windows`)**：基于操作系统文件锁跟踪各个活动 TUI 窗口。执行 `/restore` 命令可跨窗口恢复上一轮未关闭的标签集合；退出时自动合并去重。

## Skills

启动或切换工作区时发现用户与项目中的 `SKILL.md`，以及当前项目启用的插件技能。使用 `~/.config/orbit/skills/<名称>/SKILL.md`（设置 `XDG_CONFIG_HOME` 时遵循该目录）或项目 `.orbit/skills/`；也兼容 `~/.claude/skills/` 和项目 `.claude/skills/`。`/skills` 查看已发现的名称与简介，`/skill <名称>` 载入完整说明。

只有发现可用技能时才向模型注册 `load_skill`，同时注入名称与简介目录；工具参数列出实际安装的名称。空目录不暴露加载工具，切换到无技能的目录时移除旧工具与旧目录。未知名称返回当前可用名称，模型不应猜测技能。完整正文按需读取，技能不能覆盖核心规则、审批边界或当前用户请求。

## 子 Agent

模型可通过 `spawn_agent` 将独立的探索或审查任务交给子 Agent，同时继续执行其他工作。默认每个父会话允许 8 个子任务并行；在配置中调整 `[subagents].max_concurrent`（1..128），或设置 `enabled = false` 关闭。批处理可用 `--disable subagents`，`--disable all` 也会关闭这组工具。

- `spawn_agent`：传入 `task`、可选 `context` 和 `role = "explore" / "review"`，立即返回稳定的 `agent_id`。默认继承父模型及有效思考档位，也可传入 `model = "连接::模型"`、`reasoning_effort`；配置的 `explore_model` / `review_model` 为对应角色提供默认模型。每次启动或续跑都重新读取模型配置，失效的模型或档位会明确报错。
- `send_agent_message`：运行中在下一次模型请求前接收补充消息；结束或中断后，在原子会话内续跑。正在最终提交或取消时需等结果返回后重试。
- `wait_agents`：等待任一子任务完成，或用 `all = true` 等待全部。等待期间不请求模型；完成结果也会在父模型请求之间自动送入。`cancel_agents` 可单独取消选定子任务，父运行取消则取消本轮全部子任务。
- `read_agent`：不传 ID 时列出本会话的子任务；传入 ID 后默认直接读取最近一轮已完成的最终回答，每页最多 16000 个 Unicode 字符。自动回传的答案最多 6000 个字符，`truncated = false` 表示完整；长报告附带 `read_more`，后续页面返回 `next_read`，固定消息 ID 以防续跑期间串页。`view = "transcript"` 从规范消息日志开头读取；显式 `message_id` / `after_message_id` 默认沿用日志分页语义，`view = "result"` 则按最终回答正文分页。运行中的子任务明确返回结果尚未就绪，不把旧报告当成本轮结果。

子 Agent 使用独立会话、上下文和工具实例，只收到任务与显式补充的上下文；项目指令继续适用。当前提供只读文件与网页工具，并与父工具集取交集；不提供命令、文件写入、MCP、跨会话记忆或嵌套代理。默认不限轮数、最多 2000 次工具调用；每 30 分钟向父代理发进度提醒，子代理继续执行。父代理先用 `read_agent` 了解情况或用 `send_agent_message` 沟通，再决定继续或通过 `cancel_agents` 终止。`[subagents].timeout_seconds` 配置提醒间隔，`0` 关闭提醒；`max_turns` / `max_tool_calls` 的 `0` 均表示不限。可写角色与 Git worktree 隔离尚未实现。

TUI 子任务复用普通工具卡片的标题与展开边框，展开后显示当前活动、调用次数、耗时、模型、任务和结果；Markdown 分割线与代码块限制在卡片内部。点击“查看”或 Ctrl+Click 打开居中的详情弹窗，显示实时执行记录，支持滚轮、翻页、工具展开和框选复制。底部输入框可继续追问，复用 `send_agent_message`：运行中排队接收，结束后沿用原子会话上下文续跑，父代理空闲时也可发送；不切换标签，父任务继续运行。详情弹窗与 `/btw` 共用自适应尺寸：半屏保持紧凑，宽屏约占八成宽度，高度随宽度增长并限制在约八成屏高；小屏自动收缩，左右留白对称。关闭按钮沿用标签页图标与 hover 样式，左右各留一格可点击区域。`Esc`、无选区时 `Ctrl+C`、关闭按钮或点击弹窗外部可关闭。进度从本地事件日志增量读取，不请求模型；长记录分批回放，框选时暂停弹窗更新，取消选区后追上最新进度。

子会话使用现有消息、代码和工具渲染，不出现在普通 `/resume` 列表中。已提交但未送达的结果会在恢复父会话时继续回传；未完成的子任务标记为中断，需明确续跑，不自动重执行。删除父会话会一并删除已关闭的子会话；仍有子会话运行或持有写入锁时拒绝删除。

## 旁路提问 (`/btw`)

`/btw <问题>` 使用当前模型与思考档位，对当前会话上下文发起一次独立的流式请求。主任务继续运行；旁路请求不调用工具，也不将问题和回答注入主会话。上下文包含已完成的工具结果以及正在生成的部分回复，未完成的工具仅作为请求记录，不伪造执行结果。

回答显示在与子代理详情共用的弹窗中，支持滚动、框选复制和链接。底部输入框支持继续追问，保留同一旁路对话的上下文与记录；生成中可以编辑下一条草稿，回答完成后发送。输入框复用主页的 Unicode 编辑、选区、粘贴与光标渲染。`Esc`、关闭按钮或点击弹窗外收起页面，生成继续；无选区时 `Ctrl+C` 仅取消当前旁路请求，有选区时复制文本。每个标签同时允许一个旁路请求，不同标签可并行。再次输入 `/btw` 重开最新记录，用 `Alt+←/→` 查看本会话其他旁路对话；新的 `/btw <问题>` 保持独立，弹窗内追问则沿用当前旁路对话。`Tab` 切换编辑与记录焦点，`Shift+Enter` 换行，`Enter` 发送；发送失败保留草稿。重启后仍可继续追问之前的旁路对话。

结束、失败或取消后的记录单独保存在 Orbit 数据库，恢复会话后仍可查看，不影响主会话消息、上下文预算或任务状态。退出程序会停止尚未结束的旁路请求；只有已经保存的记录可恢复。

## 交互式服务连接管理 (`/connect`)

在 TUI 中输入 `/connect`，无需手动编辑配置文件即可添加或管理大模型服务：

- **官方账号连接**：直接通过内置 OAuth 流程授权 Google Antigravity、Google Gemini CLI、ChatGPT 等账号。
- **自定义 API 连接**：
  - 支持 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages 协议。
  - 支持任意自定义 Base URL（兼容本地 Ollama、vLLM 或第三方中转网关）。
  - 点击“读取模型”自动向服务的 `/models` 接口查询可用模型列表，无需逐个手填。
  - 支持原地展开模型高级设置：上下文总额度、独立输入窗口、最大输出上限、多模态支持以及思考强度档位。
- **凭据安全隔离**：通过 `/connect` 录入的 API Key 由 `orbit-auth` 写入独立凭据库，连接配置使用 `credential` 引用。手写配置仍支持明文 `api_key`（示例配置也展示该字段），不要把含真实密钥的配置提交到版本库。

模型接口提供的能力用于更新模型目录；对于只返回模型 ID 的官方 DeepSeek 接口，Orbit 为 `deepseek-flash` 和 `deepseek-v4-pro` 补充已核对的 `none / low / high / max` 思考档位，默认 `high`。手动管理的模型列表同样获得这些默认能力，显式配置的思考档位优先；其他端点和未知模型的思考协议需由服务端或连接高级设置提供能力。

TUI 每秒检测配置文件变化，并每 15 分钟异步刷新所有连接的模型目录（账号登录、API Key 及无需认证的自定义服务）；`/model refresh` 可立即刷新并打开模型选择器。能力变化同步到所有标签，保留仍受支持的当前思考档位；正在进行的回复使用原客户端和额度，结束后应用更新。自动更新不会打开选择器。

各连接独立刷新，失败时保留对应缓存或现有目录；缓存按服务地址、协议和认证身份隔离。普通 API 会读取完整分页，并保留接口提供的能力信息；Claude 的容量、图像输入与 adaptive thinking 思考档位直接来自模型接口。Google Gemini CLI 从配额接口补充模型 ID，缺少某个配额项不会删除已配置模型。

公开模型规格来自 [models.dev](https://models.dev/)，由 [model_metadata.rs](src/model_metadata.rs) 补齐 API 模型缺少的上下文、输入与输出容量、视觉能力，以及已支持的官方思考档位。服务地址和模型 ID 必须精确匹配；共用地址的目录若对同一模型给出冲突规格，则不自动采用。优先级为显式配置、账号或 API 返回的能力、公共规格；公共规格不会新增可用模型，也不代表订阅额度或访问权限。输出容量仅作为上限，不提高用户设置的输出预算。

公共规格缓存位于认证目录下的 `model-metadata/catalog.json`，有效期 24 小时。刷新复用网页工具的代理和地址检查，不发送账号凭据，等待最多三秒；失败时使用旧缓存或 [内置快照](src/model_metadata.json)。所有 API 连接均关闭 `auto_refresh_models` 时不联网更新规格。维护者可运行 `orbit model-metadata crates/orbit-cli/src/model_metadata.json` 更新内置快照；导出命令遵循 `[web]` 配置，保留来源信息；MIT 许可见 [LICENSE.models-dev](assets/LICENSE.models-dev)，不需要登录。快照按模型逐行保存，方便审查数据差异。

原 TUI 的 `account_models.json` 移至 [account_models/bootstrap.json](src/account_models/bootstrap.json)，仅作为 OAuth 账号首次连接时的离线起始目录；后续模型可用性由账号接口刷新，API 模型由对应服务的发现接口提供，不能用初始目录推断全部支持模型。

通过 `/connect` 手动启用的列表（`managed_models = true`）保持模型选择与显式能力设置，仍同步这些模型缺少的能力；自动目录会同步新增与下线的模型。服务不提供模型目录时，可在对应 `[providers.<名称>]` 下设置 `auto_refresh_models = false`，继续使用手动配置。

## 常用命令与交互指令

### 交互式快捷指令 (Slash Commands)

- `/connect`：打开连接配置向导面板。
- `/model [供应商::模型名]`：交互式或直接切换当前会话所用的模型与思考强度。
- `/model refresh`：刷新模型目录并同步当前会话的模型能力。
- `/reasoning [档位]`：查看可用思考档位，或设置当前模型的思考强度。
- `/compact`：手动触发上下文分层压缩，将旧工具记录归档并生成增量摘要。
- `/btw [问题]`：旁路询问当前上下文，主任务继续运行；不带问题时重开记录。
- `/resume [会话ID]`：打开当前项目的历史会话列表，支持按标题模糊搜索并秒级恢复。
- `/restore`：打开窗口恢复选择器，恢复上一轮未关闭的会话标签。上方的“全选 / 清空”支持悬停和点击，显示已选数量；当前行的长标题自动横向滚动。按空格切换当前行的选择，`Enter` 恢复选中的会话；`Esc` 或 `Ctrl+C` 关闭选择器并清空恢复命令，返回输入框。单个会话恢复失败时保留原标签、显示原因，并继续恢复其余选中的会话。
- `/cd <目录>`：在保留会话历史的前提下平滑切换当前会话的工作区根目录。
- `/editor [初始文本]`：暂停接管终端，调出系统的外部编辑器（`$VISUAL` 或 `$EDITOR`）编写长文本草稿。
- `/mode [ask|auto|yolo]`：切换当前会话的权限审批模式。
- `/status`：查看当前会话 ID、数据库路径、上下文占用以及验证指纹状态。
- `/changes`：核对自当前任务开始以来的基线变更与文件修改收据。

### 命令行常用子命令

```sh
# 启动交互式 TUI
orbit tui

# 恢复指定历史会话
orbit tui --resume <SESSION_ID>

# 单次命令行对话模式
orbit chat "分析并修复 src/main.rs 中的编译错误"

# 认证管理
orbit auth login google
orbit auth list

# 会话与项目管理
orbit sessions list
orbit sessions show <SESSION_ID>
orbit projects list
```

## 多模态与附件支持

- **图片拖放与剪贴板读取**：支持直接将 PNG、JPEG、GIF、WebP 图片文件拖入终端，或使用 `Ctrl+V`（部分终端 `Alt+V`）直接通过 `arboard` 读取系统剪贴板位图。
- **附件缩略图**：输入框内显示“图片 N”和 4 列、2 行内的小缩略图，不显示长文件名；等待或失败时显示图片图标，保留点击选择和删除操作。
- **去重存储**：附件自动复制到全局 `orbit.attachments` 存储池并按内容 SHA-256 去重，不向用户工作区目录写入垃圾缓存。
- **文档提取**：配合 `read_document` 工具，可直接让模型读取 PDF、Word、Excel、PPT 等文档的结构化 Markdown 解析结果。
