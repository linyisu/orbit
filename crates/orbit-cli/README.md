# Orbit CLI

运行 `orbit tui`，通过 `/connect` 添加连接，无需手写供应商配置。指定的配置文件不存在时，TUI 先打开连接界面；取消不会创建配置或会话。

## 连接服务

官方账号沿用浏览器授权，DeepSeek API 和智谱 Coding Plan 使用密钥验证。选择“自定义服务”，先填写连接名称、Base URL、协议与 API Key，在同一个面板内选择模型：

- 支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。
- Base URL 保留自定义路径，不自动添加 `/v1`；支持 HTTP 本地服务。自定义服务使用 API Key 认证。
- 点击“读取模型”请求服务的 `models` 接口，不发送推理请求。可搜索、多选、指定默认模型；接口不提供目录时，通过“添加模型”逐个录入。
- 每行“设置”原地展开，独立配置上下文容量、输入窗口、输出上限、图片输入和思考能力。未提供的能力保持未设置。
- 协议通过同排单选按钮设置；添加模型和思考设置均在当前面板完成，思考强度使用同排多选按钮。滚轮滚动内容，底部固定保存与取消，保存前不写入配置。
- “管理已有连接”可重新编辑连接和模型。已有密钥不回填，留空保留，填写新密钥才替换，套餐账号的服务地址由认证流程管理。
- 保存后刷新当前模型列表；第一次连接同时成为默认供应商。保存后当前模型参数即时更新，重名的新连接会被拒绝。

API Key 保存在 `orbit-auth` 的私有凭据目录，配置只写凭据引用。连接草稿不进入会话历史；保存前校验完整配置，通过临时文件替换写入，再由同一配置入口重新读取。原有内联 `api_key` 配置仍可读取，不自动迁移或改写。已由用户管理的模型列表不会被后台发现重新扩充或覆盖，重新发现的模型只加入选择候选。

## 模块职责

- `config`：配置类型、解析、校验及运行时参数转换。
- `connections`：官方和自定义连接的配置生成、保存与重新加载。
- `account_models`：账号模型发现及缓存。
- `tui/connect*`：连接交互及进度展示。
- `orbit-auth`：凭据持久化、读取、刷新及使用范围检查；不负责应用配置文件。

配置路径继续由 `--config` / `orbit_config` 指定，默认 `config.toml`。认证目录由入口解析后显式传入各模块。`main.rs` 负责命令分发和应用启动，不定义供应商配置及写入逻辑。

## 多窗口会话与标签

`orbit tui` 默认只打开新的空白首页。执行 `/restore` 后，补全区域显示上一轮未关闭的会话标题，默认全选；↑↓ 移动、Space 勾选、Enter 恢复、Esc 返回，也支持鼠标勾选和滚轮滚动。输入文字筛选标题，隐藏项保持原来的选择；顶部「全选 / 清空」作用于所有项。已打开的会话复用现有标签，不产生副本。关闭标签或不恢复旧标签不会删除会话，仍可通过 `/resume` 找回。输入草稿和滚动位置属于各自窗口，不跨窗口共享。

同时存活的多个 TUI 属于同一轮，每个窗口独立保存自己的未关闭标签；最后一个退出时合并去重，替换上一轮恢复快照。同一轮新开的窗口仍使用同一份旧快照。空白首页不入快照；异常退出通过 OS 文件锁判断，并在后续窗口加入或退出时恢复最近保存的记录。

同一会话可以在多个 TUI 中打开。消息、思考、工具结果、标题和完成状态通过共享数据库同步，运行中的文字增量约每 200ms 更新，后台标签也会更新。每个会话同时只允许一个请求写入；另一个窗口发送时会保留输入并提示等待，结束后可以接着发送。权限确认、取消操作仍由发起请求的窗口处理；关闭该窗口会取消其任务，不会把任务转移到其他窗口。

窗口生命周期及恢复快照放在 `orbit-store::tui_windows`，会话同步查询放在 `orbit-store::tui_sessions`，窗口端的增量回放放在 `tui/session_sync.rs`。运行时写锁在请求结束后释放；命令行 `orbit chat` 仍保留原有独占生命周期。

运行中的上下文占用、上下文容量、计时和暂停状态由请求发起窗口发布，其他窗口使用同一份状态；回放不会用旧历史覆盖实时用量。`/mode`、Shift+Tab 及“本会话始终允许”的文件授权属于共享会话设置，跨窗口及恢复后保持一致，新会话默认为 auto。模型与思考强度继续随会话同步。

### TUI 主题

`tui/theme.rs` 统一定义界面语义颜色、代码语法高亮和颜色混合规则。组件通过 `THEME` 取色，不再在视图文件内定义 RGB 或终端颜色常量；`Color::Reset` 表示继承终端颜色，语法高亮的 RGB 转换不属于独立配色。`tui/workspace.rs` 在跨目录切换时一起绑定审计目录、模型配置及工作区提示，保留会话选择的模型。

### 多终端会话同步

共享的对象是会话状态：消息、模型、思考强度、权限模式、目录及运行状态。其他窗口移动会话目录后，空闲窗口会自动重建该目录的工具、审批、审计和系统提示，无需退出或重新打开。发送与其他窗口更新撞在一起时，在创建请求前刷新快照并自动重试，保留原输入和附件；仍使用写锁防止同时执行两个请求。

草稿、滚动位置和展开状态属于各窗口的本地交互状态。当前审批及取消仍由请求发起窗口处理，尚不能称为所有操作完全同步；将它们改为共享请求/响应状态是后续完善点。实现这些行为不以独立后台服务为前提。
