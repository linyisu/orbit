# orbit-service

应用服务层，协调会话、模型、工具、审批和子 Agent。TUI、GUI 通过同一协议使用本库。

## 入口

- [workspace/](src/workspace/)：服务生命周期、会话 actor、请求与事件分页。
- [session.rs](src/session.rs)、[execution.rs](src/execution.rs)：会话恢复、Agent 启动与运行结果。
- [tools.rs](src/tools.rs)、[planning.rs](src/planning.rs)、[user_input.rs](src/user_input.rs)：工具装配、计划与问答。
- [subagents.rs](src/subagents.rs)、[side_questions.rs](src/side_questions.rs)：子任务与旁路提问。子 Agent 的原生操作与模型工具共用类型化控制入口和授权规则。
- [context/](src/context/)、[extensions/](src/extensions/)：指令、记忆、技能与插件。
- [workspace/library.rs](src/workspace/library.rs)：无会话全局管理、有界资源快照与会话应用恢复。

## 生命周期

同一数据库由共享服务管理，会话 actor 串行处理状态变更。客户端断开后任务继续；服务重启后标记中断，不自动重跑副作用命令。
运行收尾保留类型化终态；持久化失败后只重试回执或快照刷新，不重复模型与工具执行。

主动停止响应后，尚未领取的暂存消息会自动开始下一轮；普通报错与服务重启保留队列，等待手动继续。
恢复运行时重新授予历史及暂存附件的文件读取权限，不扩大到附件所在目录。
手动压缩允许空提示词，由服务统一记录为维护操作；切换到较小上下文模型后仍可执行。原始历史先归档，摘要请求按预算分批。
压缩失败保留具体原因；固定指令、工具定义或最新用户请求无法容纳时，报告各项预算。
自动整理失败但输入仍可发送时继续任务；窗口超限时可从已归档证据摘录恢复，
恢复记录与完整模型摘要明确区分。维护失败不覆盖最后有效上下文，重启后仍可重试整理或切换模型继续。
切换模型成功后重新估算历史和工具定义，发布新模型的上下文占用；失败任务仍保留在历史中，不自动重试。

Plan 只允许只读操作，批准后进入 Build，工具审批仍生效。MCP 可异步应用到已有会话；当前运行保留原工具集，后续发送使用新工具。
`CancelPlan` 仅允许智能体放弃自己进入且尚未提交审阅的草案；用户选择的 Plan、
已提交审阅及用户反馈中的计划不能自行解除。取消不批准旧计划，也不创建项目任务。
共享审批模式同时驱动工具调用与文件访问。YOLO 直接执行，Auto 自动执行已启用的 MCP 工具；
切换模式先持久化再发布，不通过额外模型调用补办 YOLO 文件权限。配置、凭据及运行目录不设路径黑名单。
计划审阅取消保留取消结果。开发子 Agent 准备失败会回滚未启动的会话及 worktree，父会话保留失败回执；
从未启动的遗留子会话不能通过追加消息绕过工作区准备。
只读子 Agent 使用父目录，`workspace_strategy` 仅控制开发角色，非 Git 开发必须显式选择 `shared`。
子 Agent 默认继承父会话当前已解析的模型接入、账号和推理配置，同一服务内后续追问保留该子 Agent 的接入。
子会话明确切换模型后，续问采用保存的新选择，运行缓存不能覆盖该选择。
显式模型及角色模型按当前配置和身份匹配的目录缓存解析，缺失时明确失败，不静默切换账号或供应商。

技能定义保存到本机 `$XDG_CONFIG_HOME/orbit/skills`（默认 `~/.config/orbit/skills`），插件市场登记与缓存保存在本机数据目录。全局管理接口不打开会话，也不加载模型。
技能导入先冻结完整来源包，再按选择安装到全局库；现有项目技能不会被移动，可从来源显式导入。
只有显式应用的扩展快照可供会话使用；应用前检查资源预算、相对路径、符号链接和技能重名。会话恢复使用数据库中的快照，全局编辑或市场刷新不影响它。
插件目前应用其声明的技能；Hook、MCP、命令与 Agent 不自动执行。没有技能的插件只可查看声明。
应用和移除须等待当前任务结束，移除不删除已有对话中的内容；能力与工具禁用策略始终保留。
MCP 导入仍由目标服务处理。配置、模型适配和持久化分别由对应 crate 负责。
额度池与当前模型的对应关系在 [workspace/usage/providers.rs](src/workspace/usage/providers.rs) 归一化，再通过协议提供给两端。

## 验证

```sh
cargo test -p orbit-service
```

[项目总览](../../README.md)

普通补充输入持久排队，当前回复正常完成后逐条启动新一轮；引导操作只将指定待发送项放入当前 Agent 的安全输入边界。失败不会自动重试，停止沿用暂存消息的续跑规则；关闭边界后收到的普通暂存仍留给下一轮。
